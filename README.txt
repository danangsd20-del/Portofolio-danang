PORTOFOLIO DANANG PRAKOSO

Cara menjalankan:
1. Ekstrak file ZIP.
2. Buka folder portfolio_danang di Visual Studio Code.
3. Buka file index.html menggunakan browser, atau jalankan dengan ekstensi Live Server.

File:
- index.html  : struktur dan konten website
- style.css   : desain dark mode responsif
- script.js   : menu mobile, tahun otomatis, dan animasi saat scroll\n- assets/foto-danang.jpg : foto profil yang ditambahkan ke kartu utama

Catatan:
- Pastikan koneksi internet tersedia untuk memuat Google Fonts.
- Tautan GitHub, LinkedIn, email, dan CV sudah dipasang.
- Bagian dokumentasi prestasi dapat diperbarui jika sudah memiliki foto atau sertifikat.
